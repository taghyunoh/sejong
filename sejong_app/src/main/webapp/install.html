홈 화면에 아이콘 추가하는 방법

Android 홈 화면에 추가

  1. 브라우저 메뉴( ⋮ 또는 화면 아래 ≡ )를 눌러요.
  2. “홈 화면에 추가”( 또는 “현재 페이지 추가” · “앱 설치” )를 눌러요.
  3. 홈 화면에 allCare 아이콘이 생겨요. 다음부턴 아이콘만 누르면 열립니다.

iPhone 홈 화면에 추가

⚠️ 아이폰은 Safari(사파리)에서만 추가돼요. 다른 앱(크롬·카카오 등)으로 열렸다면 주소를 복사해 사파리로 열어 주세요.
  1. 화면 아래 가운데 공유 버튼(□ 위에 ↑)을 눌러요.
  2. 목록을 내려 “홈 화면에 추가”를 눌러요.
  3. 오른쪽 위 “추가”를 누르면 완료!
