# sejong_app 세션 만료 → 자동 로그아웃 처리 (2026-07-12)

## 증상
로그인 후 앱을 **오래 방치**하면 이후 아무 동작도 안 되던 문제.

## 원인
- `web.xml` 에 `<session-timeout>` 이 없어 **톰캣 기본값(30분)** 으로 세션 만료.
- 만료되면 `session.getAttribute("user")` 가 null → `mainPage.do` 의 `user.getGender()` 에서 **NPE(500)**, AJAX 는 세션 user 가 없어 **조용히 실패**.
- 만료를 감지해 로그인으로 되돌리는 장치(인터셉터) 자체가 **없었음** (dispatcher 에 localeChangeInterceptor 만 존재).
- 앱은 네이티브 WebView 라 **앱 재실행 시**엔 저장 폰번호로 `autoLogin.do` 재로그인되지만, **WebView 가 열린 채 방치되다 만료**되면 복구 경로가 없었음.

## 조치 (사용자 결정: 만료 시 로그인 화면 복귀 + 자동로그인 존중 / 유지시간 1시간)

| 변경 | 파일 | 내용 |
|---|---|---|
| **세션 유지 1시간 명시** | `WEB-INF/web.xml` | `<session-config>` 에 `<session-timeout>60</session-timeout>` 추가 (XSD 상 `tracking-mode` 보다 **먼저** 와야 함) |
| **세션 체크 인터셉터 신설** | `util/SessionCheckInterceptor.java` (신규) | `preHandle` 에서 세션 user null 이면: **AJAX → 401 `{sessionExpired:true}` JSON**, **페이지 → `/loginPage.do` 리다이렉트**. 로그인 전 흐름(로그인/가입/약관/자동로그인)은 `PUBLIC_URIS` 화이트리스트로 통과 |
| **인터셉터 등록** | `springmvc/dispatcher-servlet.xml` | `RequestMappingHandlerMapping` 의 interceptors 에 `sessionCheckInterceptor` 추가 + 명시적 bean 등록 (component-scan 은 `@Controller` 만 잡음) |
| **전역 401 처리** | `asset/js/commonUtil.js` | `$(document).ajaxError` 로 401 감지 → `loginPage.do` 이동(중복/무한새로고침 방지 래치). 모든 jQuery `$.ajax` 를 한 곳에서 커버 |
| **mainPage NPE 방어** | `login/web/LoginController.mainPage` | user null 이면 `redirect:/loginPage.do` (평시엔 인터셉터가 먼저 차단) |

## 복구 흐름 (자동로그인 존중)
만료 → (페이지)리다이렉트 / (AJAX)401→JS이동 → **`loginPage.do`** 진입 → `callAndroid("f101")` 로 네이티브 저장정보 조회 → **자동로그인 켜져 있으면 저장 폰번호로 `autoLogin.do` 즉시 재로그인 → mainPage 복귀**(끊김 없음). 자동로그인 꺼져 있으면 로그인 화면 유지(재인증).

## 화이트리스트(로그인 전 접근 허용) — `SessionCheckInterceptor.PUBLIC_URIS`
`index.do / loginPage.do / sendSensApi.do / loginCheck.do / autoLogin.do / registerUser.do / updateUser.do / User.do / testUser.do / testUser2.do / testUser3.do / callback.do / getSignList.do / alldelete.do / sampleAjax.do`
- 로그인 후 화면(goBloodPage/goRegisterPage/register/foodMain/… )은 **모두 보호 대상**(세션 필요)이 맞음.
- 정적파일(css/js/img)은 `servlet-mapping` 이 `*.do` 만 DispatcherServlet 으로 보내므로 **애초에 인터셉터를 안 탐**.

## 배포
- **자바(.java)·XML(web.xml, dispatcher-servlet.xml)·JS(commonUtil.js) 변경 → WAR 재빌드 + 재배포 필수.**
- Eclipse: 외부 편집 반영 위해 **프로젝트 F5(Refresh) → Clean → Servers Clean/재배포 → Stop/Start**.

## 검증 방법
1. 로그인 후 60분 방치(또는 임시로 `session-timeout` 을 1분으로 낮춰 테스트) → 화면 탭/새로고침 시 **로그인 화면으로 이동**(자동로그인 켜면 자동 복귀), 500/빈화면 아님.
2. 만료 상태에서 데이터 AJAX 호출 시 Network 탭에 **401** + 즉시 로그인 이동 확인.
