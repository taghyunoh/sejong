# sejong_app 안정화 변경 이력 (2026-07-11)

환자용 모바일 앱(allCare, `allcare24.kr/app`)의 **로딩 지연·i-SENS 재로그인·크래시·화면 튕김·빈화면**을 근본 원인부터 정리한 이력.

---

## 1. 로딩 / 성능

| 변경 | 파일 | 내용 |
|---|---|---|
| 외부 CGM/토큰 호출 타임아웃 | `blood/web/BloodController.java` | 모든 `HttpURLConnection` 에 `setConnectTimeout(5000)`/`setReadTimeout(8000)` — **무한 대기(행) 차단** |
| SMS 호출 타임아웃 | `util/Gabia_SMSUtil.java` | 2곳 동일 타임아웃 |
| DB 커넥션풀 튜닝 | `spring/context-datasource.xml` | `maxTotal=20`, `validationQuery=SELECT 1`, `testOnBorrow`, 유휴/누수 회수, `connectionProperties=connectTimeout=5000;socketTimeout=60000` (원격 DB 행 방지) |
| 외부 재수집 비동기화 | `login/main.jsp`, `main/FAHR_00.jsp` | `getBloodData` 의 `$.ajax async:false → true` — 화면이 외부응답을 기다리지 않고 즉시 렌더 |

> **핵심**: 로딩 지연은 하드웨어(4GB)가 아니라 **"진입 시 외부 CGM을 동기로 무한 대기"** 하던 구조가 원인이었음. 비동기+타임아웃으로 해소.

## 2. i-SENS 토큰 / 연동

| 변경 | 파일 | 내용 |
|---|---|---|
| **토큰 갱신 Content-Type** | `BloodController.refreshToken` | `Content-Type: application/x-www-form-urlencoded` 누락 → i-SENS 거부 → 갱신실패 → **재로그인 반복**의 원인. `getToken` 과 동일하게 추가 |
| **서버측 자동 갱신** | `BloodController.getBloodData` + `refreshAndSaveToken`(신설) | cgms 401/403 → 서버가 refresh_token 으로 재발급 후 1회 재시도. 실패 시 `Data="REAUTH"`. sejong-web 방식 이식 → **클라이언트 refresh 루프 제거** |
| 홈 안내문구 = 연동상태 기준 | `login/main.jsp` | 기존엔 "혈당값 0/없음"으로 판단해 **연동됐는데도 "로그인 해주세요"** 오표시. `window.__hasToken`(tokenYn) 기준으로 분기: 연동됨→"혈당기 착용" / 미연동→"연동 필요" |
| **연동 UX 분리** | `main/FAHR_00.jsp` | **최초 미연동(토큰 없음) → i-SENS 로그인 자동 이동(`getAuth`)** / **재연동(토큰 만료, REAUTH) → "재연동 [연동하기]" 배너+버튼(`showConnectGuide`)** |
| **튕김 뿌리 제거** | `asset/js/commonUtil.js` | AJAX 가 200인데 JSON 파싱 실패 시 `location.href=/index.do` 로 **무조건 튕기던** 로직 제거 → 로그만 남기고 화면 유지. (연속혈당 홈/빈화면 튕김의 근본) |

- **자바(.java) 변경 포함 → WAR 재빌드 필수.** JSP/JS 복사만으론 자바 반영 안 됨.
- **매퍼 XML(Login_SQL) 변경 → 서버 재시작 필요** (MyBatis 는 기동 시 로드).

## 7. 주의사항

- **localhost 한계**: i-SENS 는 등록된 도메인으로만 OAuth 리다이렉트 허용. `localhost` 는 미등록이라 **최초 연동/재연동이 localhost 에선 불가** (실도메인에서 정상). 단 서버측 refresh(서버→i-SENS 직접호출)는 localhost 에서도 동작.
- **데이터 없음 = 정상**: 혈당기(CGM 센서) 미착용이면 데이터 0건이 정상. 앱은 "데이터가 없습니다" + (연동상태에 따른) 안내를 표시.
- **모바일은 자동 수집 유지**: 웹(관리자/의사, `sejong-web`)은 수동 "혈당 가져오기"(`syncPatientBlood.do`), 모바일(환자)은 진입 시 자동 수집이 맞음. 수동 버튼 도입 X.
- **USER_UUID 기준**: i-SENS 토큰은 `T_BLDCON_MST` 에 `USER_UUID` 로 저장. 웹/앱이 같은 사람을 다른 USER_UUID 로 인식하면 "웹은 연동/앱은 미연동"처럼 갈릴 수 있음(중복 사용자 주의). 앱은 `getUser(phone)` 의 USER_UUID 사용.
