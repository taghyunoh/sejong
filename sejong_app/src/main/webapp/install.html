홈 화면에 아이콘 추가하는 방법

Android 홈 화면에 추가

  1. 화면 아래 “홈 화면에 추가/앱 설치” 안내가 뜨면 눌러요.
  2. 안 뜨면 오른쪽 위 ⋮ (점 3개) → “앱 설치” 또는 “홈 화면에 추가”
  3. 설치를 누르면 홈 화면에 allCare 아이콘이 생겨요.

iPhone 홈 화면에 추가

⚠️ 아이폰은 Safari(사파리)에서만 추가돼요. 다른 앱(크롬·카카오 등)으로 열렸다면 주소를 복사해 사파리로 열어 주세요.
  1. 화면 아래 가운데 공유 버튼(□ 위에 ↑)을 눌러요.
  2. 목록을 내려 “홈 화면에 추가”를 눌러요.
  3. 오른쪽 위 “추가”를 누르면 완료!
