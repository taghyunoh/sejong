# 새 개발 PC에서 Gemini 키 설정 — 2026-08-13

> **왜 필요한가** : `application.properties` 는 `api.gemini.key = ${GEMINI_API_KEY:}` **참조만** 한다.
> 실제 키는 **소스에도 WAR 에도 없고** OS 환경변수 한 곳에만 있다 —
> ***PC 를 바꾸면 챗봇이 조용히 죽는다*** (화면엔 에러 없이 안내문구만 뜬다).
> 키가 없을 때의 응답 = `{"IsSucceed":false,"Message":"LLM 미설정"}`.

---

## 0. 준비 — 키를 어디서 얻나

- **정본 = 운영 서버** `/web/tomcat9/bin/setenv.sh` 의 `GEMINI_API_KEY` (MobaXterm 세션 `2.세종_TP(hannetit02)`)
- 또는 [Google AI Studio → API keys](https://aistudio.google.com/apikey) — ⚠**결제(유료)가 걸린 프로젝트의 키**여야 한다.
  결제는 **프로젝트 단위**라 프로젝트가 다르면 무료 티어로 동작한다.
- 현재 키(2026-08-13 기준) : `AQ.Ab8RN6Ie…` **53자** (옛 무료 키 `AQ.Ab8RN6Lu…` 와 앞 9자가 같으니 **10~11번째 글자로 구분**)

⚠**환자 CGM 혈당이 프롬프트에 들어간다** — 무료 티어면 구글 학습에 쓰인다. 유료 키인지 반드시 확인할 것(§3).

## 1. Windows 개발 PC — 환경변수 등록

PowerShell 에서 **아래 3줄을 한 줄씩** 실행. 프롬프트가 뜨면 ***키만*** 붙여넣는다.

```powershell
$sec = Read-Host "새 키 붙여넣고 Enter" -AsSecureString
$K = [Runtime.InteropServices.Marshal]::PtrToStringAuto([Runtime.InteropServices.Marshal]::SecureStringToBSTR($sec))
"길이=$($K.Length)  앞11자=$($K.Substring(0,11))"      # ← 53 / AQ.Ab8RN6Ie 확인
```
```powershell
[Environment]::SetEnvironmentVariable('GEMINI_API_KEY',$K,'User')
Remove-Variable K,sec
```

- `setx GEMINI_API_KEY "키"` 도 같은 자리(HKCU)지만 **명령 히스토리에 키가 남는다.** 위 방식을 쓴다.
- ⚠**클립보드 우회 금지** — 「명령을 복사해 붙여넣으세요」라고 안내하는 순간 클립보드가 그 명령으로 덮인다.
  실제로 `Get-Clipboard` 로 키를 읽으려다 **355자 명령문을 환경변수에 써 버린 적이 있다**(2026-08-13).

## 2. Eclipse 완전 재시작 — ***이걸 빼먹으면 옛 키로 계속 호출된다***

환경변수는 **프로세스가 생성될 때만** 상속된다. **서버(Tomcat)만 restart 해도 안 된다** —
Eclipse 가 실행 시점의 환경을 물고 있어 그 자식인 톰캣도 옛 값을 받는다.

1. Eclipse 완전 종료 (작업관리자에 `eclipse.exe` 없음 확인)
2. Eclipse 재실행 → 톰캣 기동

**확인법** (평문 노출 없이) :
```powershell
[Environment]::GetEnvironmentVariable('GEMINI_API_KEY','User') -eq $env:GEMINI_API_KEY
```
- `False` → 아직 옛 프로세스. 재시작 필요
- 새로 연 셸에서 `True` → 정상

⚠**새 창을 열어도 계속 `False` 인 경우** (2026-08-13 실제 발생) — 창을 띄워주는 부모
(이미 떠 있는 Windows Terminal·작업표시줄 아이콘·Explorer)가 **옛 환경을 캐시**하고 있으면
새 창도 옛 키를 상속받는다. 옛 키도 53자라 길이로는 구분 안 됨 — 아래로 내용을 비교한다:
```powershell
"proc11=$($env:GEMINI_API_KEY.Substring(0,11)) / user11=$([Environment]::GetEnvironmentVariable('GEMINI_API_KEY','User').Substring(0,11))"
```
`proc11` 이 옛 키(`…Lu`)면 부모가 낡은 것. **로그아웃 후 재로그인**(또는 재부팅)이 가장 확실하다
— 실제로 이걸로 해결했다. 재로그인하면 Eclipse 도 자연히 새 키를 받는다.

## 3. 검증 — 2단계로 본다

### ⓐ 키 자체가 유료인가 (API 직접)

```powershell
$K = [Environment]::GetEnvironmentVariable('GEMINI_API_KEY','User')
$body = '{"contents":[{"parts":[{"text":"ping"}]}]}'
$jobs = 1..12 | ForEach-Object { Start-ThreadJob -ScriptBlock { param($k,$b)
  try { (Invoke-WebRequest -Uri "https://generativelanguage.googleapis.com/v1beta/models/gemini-flash-latest:generateContent" `
    -Method POST -Headers @{'x-goog-api-key'=$k} -ContentType 'application/json' -Body $b -TimeoutSec 40).StatusCode }
  catch { $c=$_.Exception.Response.StatusCode.value__
    $t=''; try{$t=(New-Object IO.StreamReader($_.Exception.Response.GetResponseStream())).ReadToEnd()}catch{}
    if($t -match 'FreeTier'){"$c-FreeTier"}else{"$c"} } } -ArgumentList $K,$body }
$jobs | Receive-Job -Wait -AutoRemoveJob | Group-Object | ForEach-Object { "$($_.Count) x $($_.Name)" }
```
- **12 x 200** → 유료 ✓
- `429-FreeTier` 가 섞이면 → **무료 키**(분당 5건 한도). 결제 걸린 프로젝트의 키로 교체해야 한다.

### ⓑ 앱이 그 키를 물었는가 (로컬 9060)

**Git Bash 용** (PowerShell 에 붙여넣으면 `@q.json` 의 `@` 가 스플래팅으로 해석돼 ParserError):

```bash
curl -s -c j.txt -o /dev/null -w 'login=%{http_code}\n' -X POST http://localhost:9060/testUser2.do -H "X-Requested-With: XMLHttpRequest"
printf '{"q":"혈당 관리 팁 한 줄만"}' > q.json
curl -s -b j.txt -X POST http://localhost:9060/blood/chatAsk.do \
  -H "Content-Type: application/json;charset=UTF-8" -H "X-Requested-With: XMLHttpRequest" \
  --data-binary @q.json -m 60 | head -c 200
```
**PowerShell 용** (curl 별칭 충돌 방지 `curl.exe` 명시 · `"@q.json"` 따옴표 필수 · 3줄 순서대로):

```powershell
curl.exe -s -c j.txt -o NUL -w "login=%{http_code}`n" -X POST http://localhost:9060/testUser2.do -H "X-Requested-With: XMLHttpRequest"
'{"q":"혈당 관리 팁 한 줄만"}' | Set-Content q.json -NoNewline -Encoding utf8
curl.exe -s -b j.txt -X POST http://localhost:9060/blood/chatAsk.do -H "Content-Type: application/json;charset=UTF-8" -H "X-Requested-With: XMLHttpRequest" --data-binary "@q.json" -m 60
```

- `IsSucceed:true` + 한글 답변 → 완료
- `"LLM 미설정"` → 환경변수가 JVM 에 안 들어갔다(§2 재시작)
- `sessionExpired:true` → 세션만 없는 것. `testUser2.do` 먼저 호출(위 `-c/-b j.txt`)
- ⚠**파라미터명은 `q`** (`question` 아님) · **한글 본문은 파일로**(인라인 `-d` 는 400)

⚠⚠**`chatAsk.do` 의 HTTP 코드로 유료/무료를 판정하지 말 것** — Gemini 가 429 여도 **앱은 200 을 돌려주고**
본문만 `IsSucceed:false` 다. 2026-08-13 에 이 방식으로 「25건 전원 200 → 유료」라 **오판했다.**
